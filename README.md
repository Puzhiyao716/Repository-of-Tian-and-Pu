# 🎮 博弈算法与在线对弈平台合集

本项目是一个包含多个独立子项目的综合性代码仓库，涵盖了从**高维空间多人在线对弈**到**组合优化问题求解**等多个领域。每个子项目均包含完整的文档与可运行代码，展示了后端服务构建、AI 搜索算法（MCTS/回溯剪枝）及前端交互等核心技术实践。

## 📂 项目结构

```text
.
├── 4d-connect-four/      # 四维四子棋多人在线对弈平台
└── perfect-group-solver/ # 卡牌游戏“拉密”求解器
```

## 🧩 子项目简介

### 1. 四维四子棋 (4D Connect Four)
> **关键词**：FastAPI · WebSocket · MCTS · 人机混合对弈

基于 FastAPI + WebSocket 构建的多人在线对弈平台。游戏在 4×4×4×4 的四维超立方体空间中进行（映射为 16×16 二维网格），支持三名玩家轮流落子。

-   **技术架构**：Python (FastAPI + Uvicorn) 后端 + 原生 HTML/JS 前端，游戏逻辑与网络层完全解耦。
-   **AI 算法**：提供三种难度电脑玩家，涵盖随机策略、标准 MCTS+UCB1 以及引入 Alphabet 剪枝的高级 Tian 型算法。
-   **核心特性**：O(1) 胜负判定（获胜线预计算）、暂停/悔棋（含撤销 AI 思考）、实时聊天与状态同步。
-   **快速启动**：安装依赖后运行 `main.py` 即可在本地 `6006` 端口体验。

👉 [查看详细文档](./FourInFour/README.md)

### 2. 卡牌游戏“拉密”求解器
> **关键词**：精确覆盖 · 回溯法 · 锚点剪枝 · 组合优化

针对特定卡牌规则（104张牌，同色顺子/同数异色）的自动求解工具，用于判断手牌是否能被完美划分为合法牌组且无剩余。

-   **核心算法**：将问题建模为精确覆盖变种，采用回溯法结合强力剪枝策略。
-   **性能优化**：使用 4×13 计数矩阵提升读写效率；采用“最约束变量启发式”（锚点剪枝），优先处理可选分组最少的牌，大幅压缩搜索空间。
-   **输出结果**：有解时返回人类可读的具体分组方案，无解时明确提示。

👉 [查看详细文档](./Rummikub/README.md)
